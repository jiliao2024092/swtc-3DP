# SLA 後固化變形模擬器

用有限元素法預測 SLA 列印件在**後固化**過程中產生的變形與殘留應力，
在 3D 模型上以熱圖顯示，並提供鑽孔工具做「改設計 → 再驗證」的比較。

---

## 這個工具能回答什麼、不能回答什麼

**能**
- 這個模型**哪裡**最容易變形／應力集中
- 設計 A 改成設計 B（加孔、改厚薄）之後，變形是變好還是變差、變多少
- 換材料、換後固化條件的相對影響
- 後固化時**哪些區域會超過 Tg**（超過就有軟化下垂風險）

**不能**
- 給出可直接用於公差設計的絕對變形量。原因見下方「模型限制」。

> **最可靠的用法是相對比較**：同一個模型改前改後跑兩次，看差異。
> 絕對值需要用實測校正過的參數才有意義。

---

## 物理模型

計入兩個機制：

### 1. 光固化收縮（多數情況的主因）

UV 從表面照入並隨深度指數衰減，表面獲得的光遠多於內部
⇒ 表面額外交聯、收縮較多 ⇒ 表裡收縮不均 ⇒ 殘留應力與翹曲。

    ε_cure(d) = 表面收縮率 × exp(−d / UV穿透深度)

**這是深色樹脂比透明樹脂容易翹的原因**——顏料讓 UV 穿透變淺，
表裡差異變大。工具實測趨勢：同一片 60×40×3 mm 薄板，
UV 穿透 8 mm（透明）翹 0.0003 mm，穿透 0.8 mm（黑色）翹 0.0013 mm。

### 2. Tg 凍結（高溫後固化才作用）

零件厚薄不均 → 升降溫速率不同 → **各區域在不同時刻通過 Tg**。
先降到 Tg 以下的區域先變硬，之後內部才收縮卻被已硬化的外殼拘束
⇒ 殘留應力。這是鋼化玻璃的經典機制。

> ⚠ **實際上這個機制多半不作用**：Formlabs 13 種樹脂的 Tg 是 77–188°C，
> 而 Form Cure 最高 80°C，**只有 Durable V2.1（Tg 77°C）在 80°C 會超過**。
> 其餘 12 種在任何 Form Cure 溫度下都不會穿越 Tg。
> 所以若關閉光固化收縮，本工具對多數材料會預測「零翹曲」——那是正確的推論，
> 不是程式壞掉。

## 資料來源與可信度

| 係數 | 來源 | 涵蓋 |
|---|---|---|
| 熱傳導率 k | Formlabs 熱性質白皮書 | 僅 6 種材料有實測 |
| 比熱 cp | 同上 | 11 種 |
| 熱膨脹係數 CTE | 同上 | 僅 6 種 |
| 玻璃轉移溫度 Tg | 同上 | 12 種 |
| 楊氏模數 E | Formlabs 材料頁（撓曲模數） | 多數有 |
| 密度 ρ、卜松比 ν | **通用假設值** | — |
| **光固化收縮、UV 穿透深度** | **★ 使用者估計值，非官方資料** | — |

來源：<https://formlabs.com/support/Thermal-properties-of-selected-Formlabs-SLA-resins/>

**只有 Clear V5 與 Rigid 10K 四項熱性質齊全**，其餘材料有缺項、以相近樹脂代用。
程式介面會標示哪些是代用值。

### 一個對可信度有利的性質

本徵應變問題有個數學性質：**位移與楊氏模數無關**
（平衡式 ∇·(E·C₀:(ε−ε\*))=0 中，均勻的 E 會被約分）。
因此：

- **變形量**只取決於 CTE、Tg、熱擴散率與幾何 —— **E 估錯不影響**
- **應力**才與 E 成正比

密度與模數用估計值是可接受的；CTE 與 Tg 的代用才需謹慎。
（`verify.py` 有實測驗證此性質：E 放大 10 倍，位移不變、應力恰為 10 倍。）

## 模型限制

**已計入**：熱梯度凍結、光固化收縮（深度衰減）

**未計入**：
1. **列印逐層殘留應力** —— 無公開資料
2. **黏彈鬆弛** —— 真實應力在 Tg 附近會鬆弛掉一部分，本模型的應力偏高（保守）
3. **Tg 以上的自重下垂** —— 只做數量級警示（`sag_check`），非精確計算
4. **材料性質隨溫度變化** —— CTE 在 Tg 上下實際會差 2–3 倍，本模型取定值

## 使用

### 執行檔
`dist/SLA後固化變形模擬/` 底下的 exe，直接雙擊。

### 原始碼
```
venv\Scripts\python.exe app.py [模型.stl]
```

### 操作
| 按鍵 | 功能 |
|---|---|
| 左鍵拖曳 / 滾輪 | 旋轉、縮放 |
| `1` `2` `3` | 切換熱圖：變形量 / 殘留應力 / 最高溫度 |
| `D` | 切換變形後形狀顯示 |
| `H` | 在滑鼠點選處鑽孔，自動重算並比較 |
| `U` | 復原上一次鑽孔 |
| `S` | 存圖 |
| `Q` | 離開 |

右下角滑桿可調變形放大倍率（實際變形通常小到肉眼看不見）。

### 網格密度

| 選項 | 元素數* | 厚度層數* | 求解時間* |
|---|---|---|---|
| 快速（保留原表面） | 20,626 | 2.5 | 數秒 |
| **標準（建議）** | **535,891** | **7.5** | **約 3–4 分鐘** |
| 精細 | 1,000,061 | 8.9 | 過久，不建議 |

\* 以 210×172×10.5 mm、10,124 三角形的實際平板零件實測。

元素數主要由 **STL 自身的表面三角形密度**決定。若「標準」仍過大，
需在 CAD 端加大弦高公差重新匯出，而不是調本工具的參數。

厚度方向至少要 5 層才抓得到光固化收縮的深度分布，
「快速」只有 2.5 層，適合快速比對、不適合看絕對值。

### 匯入失敗時

工具會在網格化前先診斷 STL 並給出具體原因：

| 訊息 | 原因 | 解法 |
|---|---|---|
| 有 N 條邊只被一個三角形使用 | 模型有破洞、非封閉實體 | CAD 補洞，或用 Meshmixer / Netfabb 修復 |
| 有 N 條非流形邊 | 多個實體重疊未做布林聯集 | CAD 中合併後再匯出 |
| 自交面 | 表面自己穿過自己 | CAD 檢查並修復 |
| 網格量過大 | STL 三角形太多 | 加大匯出弦高公差 |

> 早期版本用 gmsh 建網格，但它需要對 STL 做「重新參數化」，
> 對真實 CAD 匯出檔極易失敗（`Wrong topology of boundary mesh for
> parametrization`、`Invalid boundary mesh`、甚至 access violation）。
> 已改用 **TetGen**——專門處理「水密三角面 → 四面體」，不需參數化，穩健得多。

### 鑽孔工具的限制
以「移除質心落在圓柱內的四面體」實作，因此**孔壁是階梯狀**的。
- 全域效果（孔是否降低整體翹曲）→ 可信，這是本工具的用途
- 孔壁的**局部應力集中值** → 不可信，會隨網格粗細變動

要看局部應力集中，需在 CAD 中真的開孔後重新匯入。

## 校正建議（讓絕對值變得可用）

1. 印一片薄板（如 60×40×3 mm），量測後固化前後的尺寸 → 得到**線收縮率**
2. 印同款但不同顏色的樹脂，比較翹曲差異 → 反推**UV 穿透深度**
3. 把量到的值填進 `materials.py` 的 `CURE_PRESETS_SHRINK`
4. 用一個已知會翹的實際零件驗證預測值

校正之後，絕對變形量才具有工程意義。

### 改動後務必執行

```
venv\Scripts\python.exe verify.py
venv\Scripts\python.exe test_pipeline.py
venv\Scripts\python.exe test_gravity.py
venv\Scripts\python.exe test_ui.py
venv\Scripts\python.exe test_render.py
```

`test_ui.py` 與 `test_render.py` 專門攔截 **GUI 的執行期錯誤**——
語法檢查對 tkinter 回呼與 PyVista 繪圖參數完全無效，
只有真的把視窗建起來、真的把畫面畫出來才抓得到。
（已實際攔截：3 碼十六進位顏色 `#a60` PyVista 不接受、
回呼引用尚未建立的元件。兩者都會讓程式一啟動就崩潰。）

這些測試在開發過程中實際抓到過六個嚴重錯誤：
形函數梯度的轉置寫反（斜四面體算錯）、
單次求解在數學上無法產生翹曲（必須改增量式）、
等間隔時間步在快速冷卻時會把凍結時序抹平（導致快冷反而算出較小應力）、
轉盤把底面水平方向也鎖死（純等向收縮竟產生 22.74 MPa 假應力）、
翹曲量測未扣剛體運動（同一零件量出 0.115 mm，實際只有 0.005 mm）、
以及 tkinter 回呼引用了尚未建立的元件（程式一啟動就 NameError 崩潰）。
**沒有這些測試，這些錯誤都會產出「看起來很專業但完全錯誤」的數字，
或是讓程式在使用者面前直接崩潰。**
