# 第一章：業務（查閱）

你能做的事集中在**查詢**與**估價**兩件事上。以下四個模組你都看得到，但畫面上不會出現新增/編輯按鈕——**這是正常的，不是壞掉**。

## 1.1 查訂單進度（工作看板）

側邊欄 →「工作看板」。四種檢視模式：

| 模式 | 用途 |
|------|------|
| **總表** | 表格列出所有訂單，可排序、篩選——**查客戶進度最常用這個** |
| **看板** | 卡片式，依狀態分欄 |
| **時間軸** | 依交期排列 |
| **Dashboard** | 統計數字總覽（總訂單、進行中、等待材料、7天內到期、已完成） |

**查特定客戶的訂單**：總表上方搜尋框輸入客戶名或 EF 單號，或用右邊的下拉篩選（工程師／機台／狀態／樹脂／類型）。

**匯出給客戶看**：點「⬇ 匯出Excel」，會把目前篩選結果匯出。

> 📷 **截圖 B**：工作看板總表，含上方篩選列與訂單表格（業務視角——注意沒有「＋新增列印工作」按鈕）

**你看不到的**：「編輯模式」「＋新增列印工作」按鈕、每列的編輯/刪除圖示。

## 1.2 查機台什麼時候有空（3D列印機預約）

側邊欄 →「3D列印機預約」。

- **甘特圖**：橫軸日期、縱軸機台，一眼看出哪台機在哪天被佔用。滑鼠移到色塊上會顯示該筆預約的業務、用途、工程師、狀態
- **表格模式**：清單形式，可排序過濾
- **機台即時狀態**（頁面下方）：每台機現在是閒置（IDLE）、列印中（PRINTING）還是異常（ERROR），以及裝的是什麼材料、剩多少。**每 30 分鐘自動更新，不用手動重整**

> 📷 **截圖 C**：預約甘特圖（業務視角——上方沒有新增預約的表單區）

**你看不到的**：整個「新增預約」表單區塊會直接隱藏，甘特圖的格子也點不動。要排機台請找工程師。

## 1.3 查材料還剩多少（材料庫存管理）

側邊欄 →「材料庫存管理」。四個分頁：

| 分頁 | 你會用到的情境 |
|------|--------------|
| **庫存總覽** | 快速看有沒有材料快用完（紅色「需叫料」標籤） |
| **材料庫存** | 逐項看每種樹脂的庫存量、機台上的量、安全庫存 |
| **消耗紀錄** | 查某段期間用掉多少材料，預設顯示最近 30 天 |
| **月度分析** | 圓餅圖／趨勢圖，看材料用量分布 |

**報價前確認材料夠不夠**：到「材料庫存」分頁，看該材料的「庫存 (L)」欄。如果狀態顯示「需叫料」，表示低於安全庫存，要先跟工程師確認。

> 📷 **截圖 D**：材料庫存分頁（業務視角——沒有「✏️ 編輯」「📦 新增入庫」按鈕）

## 1.4 自己跑估價（3D列印估價）

**這是業務唯一能實際「產出東西」的模組**，權限跟工程師、主管完全一樣。

### 基本流程

1. 側邊欄 →「3D列印估價」
2. 上傳模型：支援 **STL / OBJ / 3MF / STEP（.step/.stp）**
3. 選機台、材料、層厚
4. 擺放模型——可以拖曳旋轉環手動調，或按「自動擺放」讓系統決定
5. 看分析報告：水密檢查、厚度、懸垂、孤島等。有問題的地方可以點擊，會在 3D 畫面上標出位置
6. 產生報價單，可以存成工單

### 3D 畫面怎麼操作

| 滑鼠 | 功能 |
|------|------|
| **右鍵拖曳** | 旋轉視角 |
| **中鍵拖曳** | 平移 |
| **滾輪** | 縮放 |
| **左鍵拖曳模型** | 移動模型位置 |
| **左鍵拖曳空白處** | 框選 |

> 跟一般 CAD 軟體習慣一致。右上角的視角方塊點任一面可以直接切到該視角。

### 報價時要注意

- **工作類型**要選對：「代工」和「評估」的計費倍率不同
- 列印時間是**估算值**，用實測校準過但極大/極小件誤差會變大，精確時間以實際切片為準
- STEP 檔是近似轉換，複雜組裝件建議再跟工程師確認

> 📷 **截圖 E**：估價系統主畫面（模型已載入、右側成本分析面板）
> 📷 **截圖 F**：估價報告產出畫面

**你看不到的**：側邊工具列的「⚙ 設定」（材料單價、計費倍率設定）——那是主管的權限。

## 1.5 登記樣品出借

側邊欄 →「異常與資源」→「樣品出借」分頁。

**這是業務少數能寫入資料的地方**：選一筆樣品 → 填借出日期 + 備註 → 登記。

> 樣品清冊本身（新增/刪除樣品品項）是 admin 專屬，你只能登記借出。

> 📷 **截圖 G**：樣品出借登記畫面

# 第二章：工程師

你有業務的**所有查詢功能**（第一章 1.1～1.5 全部適用），另外多了**建立與編輯**的權限。這章只講你多出來的部分。

## 2.1 開列印工作單（工作看板）

### 新增

1. 工作看板 → 點「**＋新增列印工作**」
2. 填 EF 單號、客戶、工程師、期望交期、機台、樹脂、類型（代工／評估）
3. 儲存

### 編輯

- **雙擊該列**直接進編輯
- 或點「**編輯模式**」後，各列會出現編輯圖示

### 進度更新

在總表直接改「進度」百分比與「狀態」欄位。狀態有：待開始／進行中／等待材料／已完成／已取消。

> 📷 **截圖 H**：工作看板新增/編輯 modal（工程師視角）

**你看不到的**：刪除圖示。工作單開錯要刪除請找主管。

### 「實際消耗量」會自動帶入

如果消耗紀錄的備註有照格式填，系統會自動把用量加總帶進工單的「實際消耗量」。格式是：

```
客戶簡稱-工作類別-EF單號
例：鑫元鴻-代工-202607020001
```

工作類別**必須**是「代工」或「評估」，EF 單號要完全一樣（含空白、大小寫），否則比對不到。

## 2.2 排機台（3D列印機預約）

### 新增預約——一律用甘特圖點選

**表單上沒有日期/時段欄位**，日期時段完全由甘特圖決定：

1. 在甘特圖上**點一格** → 當日單一時段
2. **點兩格** → 框出跨天／跨時段範圍（含跨機台）
3. 或**雙擊格子**快速開啟新增視窗並帶入該時段
4. 表單填：業務、客戶/案號/備註、是否已下單、目的、負責工程師、狀態
5. 儲存

> 點選中的格子會顯示成半透明黃色。點甘特圖或表單以外的空白處可以取消選取。
> 連續時段的預約會**合併顯示**成一整段，不會逐格斷開。

> 📷 **截圖 I**：甘特圖點選時段的狀態（黃色半透明格）
> 📷 **截圖 J**：新增預約表單（「已選時段」為唯讀）

### 逾期判斷

逾期不是只看日期，是看**時段結束時刻**：

| 時段 | 幾點算結束 |
|------|----------|
| 上午 | 12:00 |
| 下午 | 18:00 |
| 晚上／全天 | 要跨過午夜（隔天）才算逾期 |

### 改狀態

預約清單的狀態欄可以直接下拉切換：待確認／執行中／已完成／異常取消。

> 「執行中」「已完成」在畫面上是**依日期即時計算**的顯示值。你手動設成「已完成」或「異常/取消」後就不會被自動覆蓋。

## 2.3 管庫存（材料庫存管理）

### 編輯庫存數量

1. 材料庫存分頁 → 點右上「**✏️ 編輯**」
2. 所有列的「庫存 (L)」「備註」變成可輸入
3. 改完點「**✓ 儲存全部**」一次寫入
4. 或點「**✕ 取消**」還原

> 是**批次編輯**：進編輯模式改完全部再一起存，不是改一格存一次。

### 新增入庫

點「📦 新增入庫」→ **先選類型（材料／耗材）** → 填名稱 + 數量 → 儲存。

| | 材料（樹脂） | 耗材（機台配件） |
|---|---|---|
| 例子 | Tough 2000、Rigid 4000 | Mixer、Resin Tank |
| 單位 | L | 個 |

> ⚠️ **入庫防呆**：如果材料名稱打錯或自創名稱，系統會攔下來提醒。因為這會另外開一筆獨立庫存，日後 Formlabs 同步進來的正式代碼**不會自動併入**，庫存會被拆成兩份對不起來。提示會列出可能想選的正式名稱。
>
> 如果其實是機台配件，記得改選「耗材」類型。

> 📷 **截圖 K**：庫存編輯模式（藍框輸入狀態）
> 📷 **截圖 L**：新增入庫對話框（含材料/耗材類型切換）

### 換樹脂槽——會自動扣材料

**這是最容易操作錯的地方，請仔細看。**

樹脂槽是「耗材」。當你把樹脂槽數量**減少**（＝從庫存領一個新槽出來用），系統會自動扣掉對應材料：

| 樹脂槽 | 每個扣除 |
|--------|---------|
| Form 4 Resin Tank | **400 ml（0.4 L）** |
| Form 4L Resin Tank | **1000 ml（1 L）** |

**為什麼要扣**：每次啟用新槽都必須先倒入最小列印材料量才能開印，這筆料進了槽就出不來。系統直接把它當作換槽當下的消耗。

#### 操作步驟

1. 材料庫存分頁 → 「✏️ 編輯」
2. 耗材區找到該樹脂槽，數量 **−1**
3. **系統跳出對話框問「這個槽是裝什麼材料」**
   - **選材料** → 扣該材料庫存，消耗紀錄留一筆
   - **選「其他」** → 不扣任何材料，只留備註紀錄（用於槽破損、誤領、盤點修正）
4. 點「✓ 儲存全部」

> 換的如果是 **Form 4L** 的槽，該材料會自動被標記「L 樹脂槽」。Form 4 的小槽不標記。
> 只有「樹脂槽」有扣料行為，**攪拌器（Mixer）沒有**。

> 📷 **截圖 M**：換槽時跳出的「這個槽裝什麼材料」對話框

#### 如果庫存不夠扣

系統只會扣到 0、不會變成負數，差額會被記錄下來並跳出**「消耗超過庫存」警示橫幅**。看到這個代表帳實不符，要查明原因（見 2.4）。

### 消耗紀錄

預設顯示**最近 30 天**。點「⏮ 載入更早一個月」可以往前多載入一個月（重新整理後回復預設）。

**紀錄類型**：

| 標示 | 意思 |
|------|------|
| 🔴 列印消耗 | 列印完成或失敗 |
| 🟠 列印中止 | 列印被取消 |
| 🟢 備料入庫 | 手動入庫 |
| ⚙️ 手動調整 | 編輯庫存、換槽扣料、刪除回補 |

**「未扣庫存」標籤**：某些消耗紀錄旁邊會有這個黃色標籤，代表這筆列印用的材料代碼版本比系統已知的最新版本舊，系統只記錄、沒有扣庫存（因為備料存的是新版本，舊版罐的用量不該扣新版庫存）。正常情況不用處理。

> 📷 **截圖 N**：消耗紀錄列表，含「未扣庫存」標籤

**你看不到的**：刪除消耗紀錄的垃圾桶圖示（主管權限）。

## 2.4 遇到「消耗超過庫存」警示怎麼辦

頁面上方出現紅色警示橫幅，表示某材料要扣的量超過帳上庫存。**你可以查，但清除警示需要主管權限。**

依序檢查：

1. **消耗紀錄有沒有重複**（同一筆列印被記兩次）
2. **材料歸屬對不對**（扣到錯的材料家族）
3. **有沒有入庫忘記登記**
4. **換槽扣料時材料是不是選錯了**

查清楚後請主管在橫幅點「✓ 已確認，清除警示」。

## 2.5 異常與資源

五個子頁（頁籤上的數字是目前筆數）：

| 子頁 | 內容 | 你能做什麼 |
|------|------|-----------|
| **客戶異常** | 客戶、異常日期、品名、工程師、狀態、保固日期、異常原因、進度狀況 | 新增／編輯 |
| **IPA 採購** | IPA 入庫與耗用紀錄 | 新增／編輯 |
| **設備清單** | 設備主檔與維護紀錄 | 新增／編輯 |
| **樣品出借** | 樣品清冊 + 借出日誌 | 登記借出（清冊本身限 admin） |
| **分析** | 統計圖表 | 檢視 |

> 預設**不顯示已完成**的項目。若列表看起來是空的（例如客戶異常顯示「無異常紀錄」但頁籤數字是 14），是因為那些都已完成——點「顯示已完成」就會出現。

**你看不到的**：刪除按鈕。

# 第三章：主管

你有工程師的**所有功能**（第一、二章全部適用），另外多了**刪除權、庫存設定權、估價定價權，以及後台管理**。這章只講你多出來的部分。

## 3.1 刪除權

三個地方你比工程師多了刪除按鈕：

| 位置 | 刪除什麼 |
|------|---------|
| 工作看板 | 列印工作單 |
| 異常與資源 | 異常/IPA/設備/樣品出借紀錄 |
| 材料庫存 → 消耗紀錄 | 單筆消耗紀錄 |

### ⚠️ 刪除消耗紀錄會回補庫存

這個特別要小心，因為**會動到庫存數字**。

刪除「列印消耗」或「列印中止」類型的紀錄時，如果這筆**當初真的有扣過庫存**，系統會把用量**加回**該材料的備料庫存，並另外記一筆「回補」紀錄註明是誰操作的。

**以下情況刪除不會回補**（確認框會明講）：

- 標示「**未扣庫存**」的紀錄——當初就沒扣，回補會憑空多出庫存
- 「**手動調整**」類型的紀錄——本身不代表真實列印消耗

> 📷 **截圖 O**：刪除消耗紀錄的確認對話框（顯示會回補多少 mL）
> 📷 **截圖 P**：刪除「未扣庫存」紀錄的確認對話框（說明不會回補）

## 3.2 庫存設定

進「材料庫存」分頁後，你比工程師多這幾個按鈕：

| 按鈕 | 用途 |
|------|------|
| **⚙️ 安全庫存設定** | 設定每種材料的低庫存警告閾值。低於這個值會顯示「需叫料」並浮到頂部橫幅 |

| **L 樹脂槽勾選格** | 標記某材料目前配著 Form 4L 的樹脂槽 |

> ⚠️ **L 樹脂槽勾選要進編輯模式**：點「✏️ 編輯」→ 勾選 → 「✓ 儲存全部」才會真的寫入。**不是點一下就存檔**，跟庫存數量、備註的操作方式一致。
>
> 換 4L 槽時系統會自動標記，通常不需要手動勾。

> 📷 **截圖 R**：材料庫存表格的 L 樹脂槽欄（編輯模式下可勾選）

## 3.4 後台管理（受限）

側邊欄會出現「**後台管理**」。你進得去，但**刻意受限**——這是為了避免主管之間互相提權或誤動最高權限帳號。

### 你可以做的

| 動作 | 說明 |
|------|------|
| 查看所有使用者 | 姓名、Email、角色、啟用狀態 |
| 新增使用者 | 填姓名、Email、初始密碼，套用角色 |
| 幫使用者**套用角色預設** | 只有三個選項：**主管／工程師／查閱** |
| 啟用／停用帳號 | |
| 匯出使用者清單 Excel | |
| 設定分頁 | 工作看板、異常與資源、3D列印機預約、3D列印樣品的清單設定 |

> 📷 **截圖 T**：後台管理使用者列表（主管視角——注意沒有刪除圖示，admin 那列也沒有編輯圖示）
> 📷 **截圖 U**：編輯使用者對話框（主管視角——只有三個角色按鈕，沒有「個別權限」勾選區）

### 你不能做的（會直接看不到，不是按了沒反應）

| 限制 | 畫面上的表現 |
|------|------------|
| **不能勾個別權限** | 編輯使用者的對話框裡**沒有**「個別權限」那一整區勾選格 |
| **不能把人設成管理員** | 「角色快速套用」只有主管/工程師/查閱三顆，沒有「管理員」 |
| **不能編輯 admin 帳號** | 使用者列表中 admin 那一列**連編輯鈕都不顯示** |
| **不能刪除使用者** | 列表沒有刪除圖示 |
| **不能改角色權限定義** | 設定分頁裡**沒有**「角色權限」這個子頁籤 |

> 這些限制在**畫面**與**資料庫規則**兩層都有把關，不是只把按鈕藏起來。

### 常見狀況：新設的主管看不到「後台管理」

「角色權限」的預設值只是**樣板**，改樣板不會回頭更新已經存在的帳號。要讓某個帳號真的取得後台權限，必須**重新對他套用一次「主管」角色**：

1. admin 或你 → 後台管理 → 使用者
2. 編輯該帳號 → 點一下「**主管**」快速套用 → 儲存
3. **請該使用者重新整理頁面**（或重新登入）

## 3.5 你該定期做的事

| 頻率 | 事項 |
|------|------|
| 每週 | 看一眼有沒有未處理的「消耗超過庫存」警示 |
| 每月 | 檢查低庫存材料，確認叫料狀況 |
| **每季** | **材料庫存實體盤點對帳一次**（見下） |

### 為什麼要定期實體盤點

換樹脂槽扣的 400/1000 ml 是**固定常數**。這個模型本身經過驗證是正確的（不會重複扣、理想狀況下誤差為零），但它**沒有自我修正機制**——如果實際情況跟假設有固定落差，誤差會一路累積下去：

| 每次偏差 | 幾次換槽後累積 1 L 誤差 |
|---------|---------------------|
| 20 ml | 50 次 |
| 50 ml | 20 次 |
| 100 ml | 10 次 |

**特別注意**：這個模型假設「舊槽裡的樹脂全部報廢」。**如果實務上會把舊槽的樹脂過濾回收倒進新槽**，系統就會扣太多，25 次換槽大約會累積 3 L 的帳面虛低（系統以為料比實際少，一直誤跳叫料警示）。若是這種作業方式，換槽時請改選「其他」並手動填實際用量。

盤點對帳方式：實際清點後，用「✏️ 編輯」把庫存數字改成實際值，系統會自動記一筆差額紀錄可供追溯。

> 技術細節與完整推導見 [INVENTORY-ALGORITHM.md 第五節](../INVENTORY-ALGORITHM.md)。
