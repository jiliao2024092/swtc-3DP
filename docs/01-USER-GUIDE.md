## 一、系統概覽

本系統是公司內部 3D 列印機（Formlabs Form4 / Form4L 等）的整合管理工具，**統一入口為 `portal/portal.html`**。

### 功能模組

| 模組 | 入口 | 說明 |
|------|------|------|
| **工作看板** | portal.html 內建 | 訂單進度追蹤，實際消耗量可從庫存消耗紀錄自動帶入 |
| **異常與資源** | portal.html 內建 | 異常紀錄、IPA / 設備維護、樣品出借 |
| **後台管理** | portal.html 內建 | 使用者管理、系統設定、角色權限 |
| **3D列印機預約** | portal.html → iframe | 機台預約、甘特圖（支援跨天）、即時狀態 |
| **材料庫存管理** | portal.html → iframe | 材料／耗材庫存、樹脂罐、消耗紀錄、月度分析 |
| **3D列印估價（Beta）** | portal.html → iframe | quote-studio.html，3D模型估價、分析報告、材料/價格設定 |

### 黑暗模式（全站）

側邊欄使用者名稱右側的 🌙／☀ 按鈕可切換黑暗／亮色模式，涵蓋全部頁面，會記住偏好，下次登入自動套用。

## 二、使用者角色

| 角色 | 預約系統 | 庫存系統 | 工作看板 / 異常 | 估價系統 | 後台管理 |
|------|---------|---------|----------------|---------|---------|
| **viewer** | 查看所有預約、機台狀態 | 查看庫存、消耗紀錄 | 查看 | 可使用估價 | — |
| **operator（工程師）** | viewer ＋ 新增/編輯/刪除預約 | viewer ＋ 編輯庫存、新增入庫 | 新增/編輯 | 可使用估價 | — |
| **manager（主管）** | operator 全部 | operator ＋ **刪除消耗紀錄**、**庫存設定**（安全庫存/顯示名稱/L槽標記） | operator ＋ 刪除 | operator ＋ **材料/價格設定** | ✅ **僅使用者管理**（見下） |
| **admin** | operator 全部 | 全部 ＋ 觸發同步、清除重建、去除重複 | 全部 ＋ 刪除 | 全部 | ✅ 全部 |

新使用者建立後預設為 viewer。admin 至後台管理頁面的「使用者」分頁設定權限，或於「角色權限」分頁調整各角色的預設權限範圍。**系統至少需保留一位 admin**：若目前只剩一位管理員，刪除該帳號或移除其管理員權限會被系統擋下。

### 主管在後台管理的權限邊界（v2.4）

主管（有 `manage_users` 權限）可以進入後台管理，但**刻意受限**，避免自我提權或誤動最高權限帳號：

| 動作 | 主管 | admin |
|------|:----:|:-----:|
| 進入後台管理「使用者」分頁 | ✅ | ✅ |
| 新增使用者 | ✅ | ✅ |
| 對其他使用者**套用角色預設** | ✅（僅主管／工程師／查閱） | ✅（含管理員） |
| **勾選個別權限** | ❌ 看不到勾選格 | ✅ |
| 編輯 admin 身分的使用者 | ❌ 連編輯鈕都不顯示 | ✅ |
| 刪除使用者 | ❌ | ✅ |
| 設定 →「角色權限」分頁 | ❌ 分頁不顯示 | ✅ |
| 設定 → 其他分頁（工作看板/異常/預約/樣品） | ✅ | ✅ |

> 這些限制在**前端畫面**與 **Firestore 安全規則**兩層都有把關，不是只靠隱藏按鈕。

## 三、功能模組說明

### 3.1 工作看板

追蹤訂單從報價到出貨的各階段進度。

- **新增訂單**：填入訂單編號、客戶、機型、狀態
- **狀態欄**：可拖拉或點選切換（報價中 / 確認 / 生產中 / 出貨 / 完成）
- **排序**：可按各欄位排序

### 3.2 異常與資源

分四個子頁籤：

| 子頁 | 說明 |
|------|------|
| **異常紀錄** | 列印異常、設備故障等事件 |
| **IPA 耗材** | IPA 入庫 / 耗用紀錄 |
| **設備維護** | 定期保養、維修紀錄 |
| **樣品出借** | 樣品清冊（主檔）+ 借出日誌 |

#### 樣品出借

樣品出借是單純的「借出日誌」：只記**樣品、借出日期、備註**，沒有借出人、歸還日期、借出時段的概念。

- **樣品清冊**（限 admin 新增/刪除）：維護樣品主檔（編號、位置、樣品名稱、材質）
- **登記出借**（viewer 即可）：選一筆樣品 → 填借出日期 + 備註 → 登記，會累積進借出統計（依樣品/材料/月份，多種圖表自由切換）
- **每月登記表 Excel 匯入**（限 admin）：上傳填好的月表（編號/位置/樣品名稱/材質 + 1~31 日欄，格內有記號＝當天借出）→ 系統自動解析月份 → 預覽各樣品借出天數與勾選日 → 確認後每個勾選格產生一筆借出紀錄。**同一個月重複匯入會先汰換舊的月表匯入紀錄**，不會重複累計
- **空白月表範本**（限 admin）：依現有清冊產生可列印的空白月表 Excel，供現場人工勾選後掃描回傳匯入
- **匯出 Excel**：一次匯出樣品清冊、出借紀錄、借出統計三個工作表

### 3.3 後台管理

- **使用者分頁**：查看所有帳號、角色，新增/編輯使用者（主管受限，見第二章）
- **設定分頁**：工作看板、異常與資源、3D列印機預約、3D列印樣品的清單設定；**角色權限**（限 admin）可調整各角色套用預設時的權限範圍

### 3.4 3D 列印機預約

#### 新增預約（operator / manager / admin）

日期／時段一律由**甘特圖點選**決定，表單不再有日期/時段輸入欄位，只顯示唯讀的「已選時段」：

1. 在甘特圖上點一格 → 當日單一時段；點兩格（含跨天、跨機台不同時段）→ 框出跨天/跨時段範圍
2. 雙擊格子可快速開啟新增視窗並帶入該格時段
3. 表單填業務、客戶/案號/備註、是否已下單、目的、負責工程師、狀態（設備欄位唯讀，隨點選自動帶入）
4. 點「儲存」

點選中的格子顯示為半透明黃色；點擊甘特圖或表單以外的空白處可取消選取。**連續時段的預約會合併顯示**成一整段。

#### 逾期判斷

逾期依時段的**結束時刻**判斷：上午時段 12:00、下午時段 18:00 算結束；晚上/全天時段要跨過午夜才算逾期。

#### 查看預約

- **甘特圖模式**（預設）：按機台分線顯示時間軸
- **表格模式**：列表，可排序、過濾

#### 即時機台狀態

頁面下方顯示機台即時狀態（IDLE / PRINTING / ERROR）、材料與剩餘量。Cloud Function 每 30 分鐘同步，前端 onSnapshot 即時推送，**不需手動重整**。

### 3.5 材料庫存管理

#### 四個分頁

| 分頁 | 內容 |
|------|------|
| **庫存總覽** | 月度消耗統計、低庫存警告、機台樹脂罐狀態 |
| **材料庫存** | 備料庫存清單、耗材清單、機台樹脂罐（摺疊）、可編輯 |
| **消耗紀錄** | 列印消耗、入庫、調整的歷史，預設 30 天 |
| **月度分析** | 圓餅圖、月度趨勢圖、詳細統計表 |

#### 材料 vs 耗材（v2.4 分離）

庫存分成兩類，**入庫時要先選類型**：

| | 材料（樹脂） | 耗材（機台配件） |
|---|---|---|
| 例子 | Tough 2000、Rigid 4000、Clear V5 | Form 4 Mixer、Form 4 Resin Tank |
| 單位 | L | 個 |
| 代碼比對 | 會做 Formlabs 家族代碼正規化與合併 | 不做，直接用輸入的名稱當識別 |
| 低庫存警示 | ✅ | ✅（一樣會浮到頂部橫幅） |

> **分類不會被靜默改變**：若某名稱已存在且分類不同（例如既有耗材被誤選成材料入庫），系統會擋下並提示切換到正確頁籤，不會讓耗材悄悄跑回材料清單。

#### 材料庫存頁欄位說明

系統偵測到 Formlabs 回傳但尚未命名的新材料代碼時，會在總覽頁顯示提示橫幅，可一鍵開啟命名。**機台配件不會出現在這個提示裡**。

| 欄位 | 來源 | 可編輯 |
|------|------|-------|
| **材料名稱** | 系統內建 + 自動偵測新材料；同家族若偵測到新版本代碼會自動改顯示最新版本名稱 | 否（顯示名稱可由 admin/主管覆寫） |
| **庫存 (L)** | `inv.stock[material].total_ml / 1000` | ✓ 編輯模式 |
| **機台上 (L)** | Cloud Function 同步自 Formlabs API | 否（自動更新） |
| **安全庫存 (L)** | 手動設定 | ✓ admin / 主管 |
| **L 樹脂槽** | 換 4L 槽時自動標記 | ✓ admin / 主管（編輯模式） |
| **狀態** | 庫存 < 安全庫存 → 需叫料 | 否（自動） |
| **備註** | 手動輸入 | ✓ 編輯模式 |

#### 整頁編輯模式

1. 點右上「✏️ 編輯」
2. 所有列的「庫存 (L)」「備註」「L 樹脂槽」勾選格啟用
3. 編輯完後點「✓ 儲存全部」→ 一次寫入 Firestore
4. 或點「✕ 取消」→ 還原

> **L 樹脂槽標記要進編輯模式打勾再按「儲存全部」**才會真的寫入，不是點一下就存檔（與庫存數量／備註的操作方式一致）。

#### 換樹脂槽會扣材料（v2.4）

樹脂槽是耗材，把它的數量**減少**（＝從庫存領一個新槽出來用）時，系統會自動扣掉對應材料：

| 耗材 | 每個扣除 |
|------|---------|
| Formlabs Form 4 Resin Tank | 400 ml（0.4 L） |
| Formlabs Form 4L Resin Tank | 1000 ml（1 L） |

**為什麼要扣**：每次啟用新槽都必須先倒入一個「最小列印材料量」才能開印，這筆料進了槽就出不來。系統直接把這個最小預留量當作換槽當下的消耗，省去逐槽追蹤存量的麻煩。

操作時會跳出對話框問「**這個槽是裝什麼材料**」：

- 選材料 → 扣該材料的備料庫存，並在消耗紀錄留一筆
- 選「**其他**」→ 不扣任何材料，只留一筆備註紀錄供稽核（用於槽未使用就報廢、盤點修正等情況）

換的如果是 **Form 4L** 的槽，該材料會自動被標記為「L 樹脂槽」（Form 4 的小槽不標記）。

只有「樹脂槽」有這個行為，**攪拌器（Mixer）沒有**。

> 若庫存不足只能扣到 0，差額會被記錄下來並跳出「消耗超過庫存」警示（見下），不會靜默消失。

#### 消耗超過庫存警示（v2.4）

當扣庫存時發現帳上不夠（只能扣到 0），差額會累計記錄並在頁面上方顯示警示橫幅。這代表帳實不符，常見原因：

- 消耗紀錄重複
- 材料歸屬錯誤
- 漏登入庫

查明處理後，可由有權限者點「✓ 已確認，清除警示」清掉累計值。

#### 新增入庫

點「📦 新增入庫」→ 選類型（材料／耗材）→ 填名稱 + 數量 → 儲存。自動寫入一筆 history（type=stockin）。

**入庫防呆**：若輸入的材料名稱對不到 Formlabs 已知家族代碼（打錯字或自創名稱），系統會攔下並提示——這種情況會另開一筆獨立庫存，日後 Formlabs 同步進來的正式代碼**不會自動併入**，庫存會被拆成兩份。提示會列出可能想選的正式名稱供確認。若其實是機台配件，提示會建議改選「耗材」類型。

#### 消耗紀錄

預設訂閱**最近 30 天**。點「⏮ 載入更早一個月」往前推 30 天（F5 後回預設）。

**紀錄類型：**

| Type | 顯示 | 說明 |
|------|------|------|
| `consume` | 🔴 列印消耗 | 列印完成 / 列印錯誤 |
| `aborted` | 🟠 列印中止 | 列印被取消 |
| `stockin` | 🟢 備料入庫 | 手動新增入庫 |
| `manual` | ⚙️ 手動調整 | 編輯庫存、換槽扣料、刪除回補等 |

**消耗以最新版本計算**：同一材料家族若出現新版本代碼（如家族最新為 FLTO2002），舊版本代碼（FLTO2001）的列印**只記錄、不扣備料庫存**——因為備料存的是新版本，舊版罐用量不該扣新版庫存。這類紀錄會顯示「**未扣庫存**」標籤，方便稽核。已知同一實際版本但代碼不同的特例（如 Rigid 10K V1.1 的 FLRG1002/FLRG1011）系統會視為同版本、正常扣庫存。此規則只影響**之後**新同步的資料，歷史紀錄不回溯。

> **v2.4 修正**：「未扣庫存」標籤先前因為前端資料處理的疏漏，實際上**從來沒有顯示過**，而且刪除這類紀錄時還會誤把材料加回庫存。此問題已修正。

#### 備註格式慣例（影響工作看板自動帶入消耗量）

編輯消耗紀錄備註時建議填：**客戶簡稱-工作類別-EF單號**（例：`鑫元鴻-代工-202607020001`）。工作類別需為「代工」或「評估」其中之一，工作看板才能依 EF 單號自動比對、加總消耗量帶入「實際消耗量」欄位。

#### 刪除消耗紀錄（admin / 主管）

消耗紀錄旁的垃圾桶圖示可刪除該筆紀錄。若該筆是「列印消耗」或「列印中止」類型**且當初有真的扣過庫存**，刪除時會**自動把用量加回同家族備料庫存**，並留一筆「回補」歷史紀錄註明操作者。

以下情況刪除**不會**動庫存數字：

- 手動調整類型（`manual`）的紀錄——本身不代表真實列印消耗
- 標示「未扣庫存」的舊版本消耗紀錄——當初就沒扣，回補會憑空多出庫存

## 四、3D 列印估價（quote-studio.html，Beta）

原本的 `quote.html` 已下線，往後估價一律使用沉浸版 `quote-studio.html`（portal 側邊欄「3D列印估價」，標有 BETA 徽章）。

### 4.1 基本流程

1. 上傳 STL / OBJ / 3MF / **STEP（.step/.stp）**模型
2. 選擇機台、材料、層厚
3. 擺放模型（可用旋轉環手動調整、或一鍵自動擺放）
4. 檢視分析報告（水密檢查、厚度、懸垂、孤島等），孤島警告可點擊在 3D 視圖標示位置
5. 產生報價單、可存成工單

### 4.2 3D 檢視操作方式

| 滑鼠操作 | 功能 |
|---------|------|
| **左鍵拖曳空白處** | 框選：拉出矩形，鬆開時矩形若與模型重疊即選取，否則取消選取 |
| **左鍵拖曳模型** | 選取並移動模型（在列印範圍內拖曳） |
| **右鍵拖曳** | 旋轉視角（不論按在模型或空白處） |
| **中鍵拖曳** | 平移視角 |
| **滾輪** | 縮放 |

### 4.3 常用操作

| 功能 | 說明 |
|------|------|
| **底視 / 360° 旋轉** | 視角列有「底視」按鈕；旋轉視角已放寬到接近整圈，可以看到模型底部 |
| **視角方塊六面 + 點擊 snap** | 右上角視角方塊有前/後/左/右/頂/底六面，點任一面直接切換 |
| **旋轉環吸附 1°** | 拖曳旋轉環預設以 1 度為單位吸附，按住 Shift 可自由角度；旋轉環在螢幕上的大小固定 |
| **支撐顯示方式** | 可切換「實體顯示 / 半透明顯示 / 只顯示支撐點」，純視覺切換不影響幾何 |
| **支撐風險熱力圖** | 視角列「🧩 支撐風險」：危險懸垂面依是否已被支撐涵蓋分色（紅＝未涵蓋、青綠＝已涵蓋） |
| **無支撐選項** | 可切換「有支撐 / 無支撐」，選無支撐時成本不會再套用預設的 15% 粗估支撐量 |
| **全螢幕檢視** | 「⛶ 全螢幕」只隱藏 portal 側欄填滿瀏覽器視窗，不用瀏覽器原生全螢幕 |
| **黑暗模式** | 由 portal 側邊欄的 🌙／☀ 統一控制，quote-studio 頁面本身無獨立切換鈕 |
| **工作類型倍率** | 成本分析面板可切換「代工 / 評估」，套用設定的計費倍率 |

### 4.4 列印時間估算

列印時間採「面積感知模型」：總時間 = 開銷（樹脂預熱等） + 每層基礎時間 × 層數 + 面積係數 × 固化體積 ÷ 層厚，並依所選材料套用實測校準的速度係數（12 種材料）。比舊版「層數 × 固定係數」更能反映形狀差異。

> **此模型每種材料僅用一個尺寸的真實列印校準，極大/極小件屬外插，僅供估算參考**，精確結果仍以實際切片/列印時間為準。

### 4.5 材料與價格設定（admin / 主管專屬）

側邊工具列「⚙ 設定」（僅 admin 或有 `manage_quote_pricing` 權限的主管可見）：

- **材料清單**：可新增/編輯/刪除材料（名稱、單價、密度）
- **計費倍率**：分別設定「代工」「評估」兩種倍率，套用在成本小計（材料＋支撐＋後處理）之上

## 六、典型使用情境

### 情境 A：列印機完成一筆列印

1. Formlabs 機台列印完成
2. **30 分鐘內** Cloud Function 自動偵測並寫入 Firestore
3. 前端 onSnapshot 即時更新：機台狀態卡片（IDLE）、消耗紀錄新增一筆、庫存頁「機台上 (L)」更新

### 情境 B：使用者手動換樹脂罐

1. 使用者拿備料一罐裝到機台上
2. Cloud Function 同步後「機台上 (L)」更新為新罐容量
3. ⚠️ **備料庫存「庫存 (L)」不會自動扣** — 需手動編輯：材料庫存頁 → ✏️ 編輯 → 該材料庫存減少 1 L → 儲存

### 情境 C：使用者更換樹脂槽（v2.4）

1. 從庫存拿一個新的 Resin Tank 裝上機台
2. 材料庫存頁 → ✏️ 編輯 → 耗材區把該樹脂槽數量 **−1**
3. 系統跳出對話框問「這個槽是裝什麼材料」→ 選材料
4. 按「✓ 儲存全部」→ 耗材數量減 1，該材料備料庫存自動扣 0.4 L（Form 4）或 1 L（Form 4L）
5. 若換的是 4L 槽，該材料會自動被標記「L 樹脂槽」

### 情境 D：admin / 主管設定安全庫存

1. 材料庫存頁 → 點「⚙️ 安全庫存設定」
2. 設定每個材料閾值（L）→ 儲存
3. 庫存低於閾值的材料顯示「需叫料」紅色標籤，並浮到頂部橫幅

### 情境 E：消耗紀錄出現 1970 年資料

Cloud Function 內建 `parse_valid_ts` 修正：Formlabs 偶爾回傳 epoch(1970) 的 `print_finished_at` 時，自動退回 `created_at` 使用。正常情況下使用者不需要處理。

### 情境 F：消耗紀錄顯示「未扣庫存」

代表這筆列印用的材料代碼版本號比系統目前已知的最新版本舊（例如家族最新是 FLTO2002，這筆是 FLTO2001）。系統判斷備料存的是新版本、舊版罐用量不該扣新版庫存，所以**只記錄不扣除**。

正常情況不需處理；若某材料家族其實仍有舊版本備料瓶在用，導致該家族庫存數字比實際多，請聯絡 admin 確認是否要為該家族加白名單排除此規則。

### 情境 G：出現「消耗超過庫存」警示（v2.4）

代表某材料要扣的量超過帳上庫存，只能扣到 0，差額被記錄下來。請依序檢查：

1. 消耗紀錄是否有重複
2. 該筆消耗的材料歸屬是否正確
3. 是否有入庫忘記登記

查明並修正後，點警示橫幅的「✓ 已確認，清除警示」清掉累計值。
