## 一、系統概覽

本系統是公司內部 3D 列印機（Formlabs Form4 / Form4L 等）的整合管理工具，**統一入口為 `portal/portal.html`**。

### 功能模組

| 模組 | 入口 | 說明 |
|------|------|------|
| **工作看板** | portal.html 內建 | 訂單進度追蹤，實際消耗量可從庫存消耗紀錄自動帶入 |
| **異常與資源** | portal.html 內建 | 異常紀錄、IPA / 設備維護 |
| **後台管理** | portal.html 內建 | 使用者管理、系統設定 |
| **3D列印機預約** | portal.html → iframe | 機台預約、甘特圖（支援跨天）、即時狀態 |
| **材料庫存管理** | portal.html → iframe | 樹脂罐、備料庫存、消耗紀錄、月度分析 |
| **3D列印估價（Beta）** | portal.html → iframe | quote-studio.html，3D模型估價、STL分析報告、材料/價格設定 |

### 黑暗模式（全站，v2.3）

側邊欄使用者名稱右側的 🌙／☀ 按鈕可切換黑暗／亮色模式，涵蓋 portal 外殼、工作看板、異常與資源、後台管理、3D列印機預約、材料庫存、3D列印估價全部頁面，會記住偏好，下次登入自動套用。

## 三、功能模組說明

### 3.1 工作看板

追蹤訂單從報價到出貨的各階段進度。

- **新增訂單**：填入訂單編號、客戶、機型、狀態
- **狀態欄**：可拖拉或點選切換（報價中 / 確認 / 生產中 / 出貨 / 完成）
- **排序**：可按各欄位排序

### 3.2 異常與資源

分四個子頁籤：

| 子頁 | 說明 |
|------|------|
| **異常紀錄** | 列印異常、設備故障等事件 |
| **IPA 耗材** | IPA 入庫 / 耗用紀錄 |
| **設備維護** | 定期保養、維修紀錄 |
| **樣品出借** | 樣品清冊（主檔）+ 借出日誌（v2.3 簡化，見下） |

#### 樣品出借（v2.3）

樣品出借是單純的「借出日誌」：只記**樣品、借出日期、備註**，沒有借出人、歸還日期、借出時段的概念。

- **樣品清冊**（限 admin 新增/刪除）：維護樣品主檔（編號、位置、樣品名稱、材質）
- **登記出借**（viewer 即可）：選一筆樣品 → 填借出日期 + 備註 → 登記，會累積進借出統計（依樣品/材料/月份，橫條/直條/環狀/折線圖自由切換維度）
- **每月登記表 Excel 匯入**（限 admin）：上傳填好的月表（編號/位置/樣品名稱/材質 + 1~31 日欄，格內有記號＝當天借出）→ 系統自動解析月份（優先讀表內標題，否則預設前一月，可手改）→ 預覽各樣品借出天數與勾選日 → 確認後每個勾選格產生一筆借出紀錄。**同一個月重複匯入會先汰換舊的月表匯入紀錄**，不會重複累計；找不到對應樣品的項目可選擇自動加入清冊
- **空白月表範本**（限 admin）：依現有清冊產生可列印的空白月表 Excel，供現場人工勾選後再掃描/拍照回傳匯入
- **匯出 Excel**：一次匯出樣品清冊、出借紀錄、借出統計三個工作表

### 3.3 後台管理（admin only）

- 使用者清單：查看所有帳號、角色
- 系統設定：workspace 全域設定

### 3.4 3D 列印機預約

#### 新增預約（editor / admin，v2.3 改為純點選）

日期／時段一律由**甘特圖點選**決定，表單不再有日期/時段/結束日期/結束時段輸入欄位，只顯示唯讀的「已選時段」：

1. 在甘特圖上點一格 → 當日單一時段；點兩格（含跨天、跨機台不同時段）→ 框出跨天/跨時段範圍
2. 雙擊格子可快速開啟新增視窗並帶入該格時段
3. 表單填業務、客戶/案號/備註、是否已下單、目的、負責工程師、狀態（設備欄位唯讀，隨點選自動帶入）
4. 點「儲存」

點選中的格子顯示為半透明黃色；點擊甘特圖或表單以外的空白處可取消目前選取。**連續時段的預約會合併顯示**成一整段，不會逐格斷開。

#### 逾期判斷（v2.3）

逾期不再只看日期，改依時段的**結束時刻**判斷：上午時段 12:00、下午時段 18:00 算結束；晚上/全天時段要跨過午夜（即隔天）才算逾期。

#### 查看預約

- **甘特圖模式**（預設）：按機台分線顯示時間軸
- **表格模式**：列表，可排序、過濾

#### 即時機台狀態

頁面下方顯示機台即時狀態（IDLE / PRINTING / ERROR）、材料與剩餘量。Cloud Function 每 30 分鐘同步，前端 onSnapshot 即時推送，**不需手動重整**。

### 3.5 材料庫存管理

#### 四個分頁

| 分頁 | 內容 |
|------|------|
| **庫存總覽** | 月度消耗統計、低庫存警告、機台樹脂罐狀態 |
| **材料庫存** | 備料庫存清單、機台樹脂罐（摺疊）、可編輯 |
| **消耗紀錄** | 列印消耗、入庫、調整的歷史，預設 30 天 |
| **月度分析** | 圓餅圖、月度趨勢圖、詳細統計表 |

#### 材料庫存頁欄位說明

系統偵測到 Formlabs 回傳但尚未命名的新材料代碼時，會在總覽頁顯示提示橫幅（僅 admin 可見），可一鍵開啟命名。**機台配件（如 Formlabs Form 4/4L 的 Mixer、Resin Tank）不是樹脂耗材，不會出現在這個提示裡**（v2.3）。

| 欄位 | 來源 | 可編輯 |
|------|------|-------|
| **材料名稱** | 系統內建 + 自動偵測新材料；同家族材料若偵測到新版本代碼會自動改顯示最新版本名稱 | 否 |
| **庫存 (L)** | `inv.stock[material].total_ml / 1000` | ✓ editor 編輯模式 |
| **機台上 (L)** | Cloud Function 同步自 Formlabs API | 否（自動更新） |
| **安全庫存 (L)** | 手動設定 | ✓ admin only |
| **狀態** | 庫存 < 安全庫存 → 需叫料 | 否（自動） |
| **備註** | 手動輸入 | ✓ editor 編輯模式 |

#### 整頁編輯模式（editor / admin）

1. 點右上「✏️ 編輯」
2. 所有列的「庫存 (L)」和「備註」啟用（藍框）
3. 編輯完後點「✓ 儲存全部」→ 一次寫入 Firestore
4. 或點「✕ 取消」→ 還原

#### 新增入庫

點「📦 新增入庫」→ 選材料 + 數量 → 儲存。自動寫入一筆 history（type=stockin）。

**入庫防呆（v2.3）**：若輸入的材料名稱對不到 Formlabs 已知家族代碼（打錯字或自創名稱），系統會攔下並提示——這種情況會另開一筆獨立庫存，日後 Formlabs 同步進來的正式代碼**不會自動併入**，庫存會被拆成兩份。提示會列出可能想選的正式名稱供確認。

#### 消耗紀錄

預設訂閱**最近 30 天**。點「⏮ 載入更早一個月」往前推 30 天（F5 後回預設）。

**紀錄類型：**

| Type | 顯示 | 說明 |
|------|------|------|
| `consume` | 🔴 列印消耗 | 列印完成 / 列印錯誤 |
| `aborted` | 🟠 列印中止 | 列印被取消 |
| `stockin` | 🟢 備料入庫 | 手動新增入庫 |
| `manual` | ⚙️ 手動調整 | 編輯庫存的差異紀錄 |

**消耗以最新版本計算（v2.3）**：同一材料家族若出現新版本代碼（如家族最新為 FLTO2002），舊版本代碼（FLTO2001）的列印**只記錄、不扣備料庫存**——因為備料存的是新版本，舊版罐用量不該扣新版庫存。這類紀錄會顯示「未扣庫存」標籤，方便稽核；已知同一實際版本但代碼不同的特例（如 Rigid 10K V1.1 的 FLRG1002/FLRG1011）系統會視為同版本、正常扣庫存。此規則只影響**之後**新同步的資料，歷史紀錄不回溯。

#### 備註格式慣例（影響工作看板自動帶入消耗量）

編輯消耗紀錄備註時建議填：**客戶簡稱-工作類別-EF單號**（例：`鑫元鴻-代工-202607020001`）。工作類別需為「代工」或「評估」其中之一，工作看板才能依 EF 單號自動比對、加總消耗量帶入「實際消耗量」欄位。

#### 刪除消耗紀錄（admin / 主管）

消耗紀錄旁的垃圾桶圖示可刪除該筆紀錄；若該筆是「列印消耗」或「列印中止」類型**且當初有真的扣過庫存**，刪除時會**自動把用量加回同家族備料庫存**，並留一筆「回補」歷史紀錄註明操作者。手動調整類型（`manual`）的紀錄、以及標示「未扣庫存」的舊版本消耗紀錄，本身都不代表真實扣庫存，刪除不會動庫存數字。

## 四、3D 列印估價（quote-studio.html，Beta）

原本的 `quote.html` 已下線，往後估價一律使用沉浸版 `quote-studio.html`（portal 側邊欄「3D列印估價」，標有 BETA 徽章）。

### 4.1 基本流程

1. 上傳 STL / OBJ / 3MF / **STEP（.step/.stp，v2.3 新增）**模型
2. 選擇機台、材料、層厚
3. 擺放模型（可用旋轉環手動調整、或一鍵自動擺放）
4. 檢視 STL 分析報告（水密檢查、厚度、懸垂、孤島等），孤島警告可點擊在 3D 視圖標示位置
5. 產生報價單、可存成工單

### 4.2 3D 檢視操作方式（v2.3 改版）

| 滑鼠操作 | 功能 |
|---------|------|
| **左鍵拖曳空白處** | 框選：拉出矩形，鬆開時矩形若與模型重疊即選取，否則取消選取 |
| **左鍵拖曳模型** | 選取並移動模型（在列印範圍內拖曳） |
| **右鍵拖曳** | 旋轉視角（不論按在模型或空白處） |
| **中鍵拖曳** | 平移視角 |
| **滾輪** | 縮放 |

> v2.3 之前是「左鍵拖曳空白處＝轉視角、右/中鍵＝平移」，現改為前述配置（貼近一般 CAD/建模軟體慣例）。

### 4.3 常用操作

| 功能 | 說明 |
|------|------|
| **底視 / 360° 旋轉** | 視角列有「底視」按鈕；旋轉視角已放寬到接近整圈，可以看到模型底部 |
| **視角方塊六面 + 點擊 snap** | 右上角視角方塊補齊前/後/左/右/頂/底六面，點任一面直接切換到該視角 |
| **旋轉環吸附 1°** | 拖曳旋轉環預設以 1 度為單位吸附，按住 Shift 可自由角度；旋轉環在螢幕上的大小固定，不會隨縮放鏡頭跟著變 |
| **支撐顯示方式**（v2.3） | 材料與參數步驟可切換「實體顯示 / 半透明顯示 / 只顯示支撐點」三種支撐材呈現方式，純視覺切換不影響幾何 |
| **支撐風險熱力圖**（v2.3） | 視角列「🧩 支撐風險」：危險懸垂面依是否已被支撐涵蓋分色（紅＝未涵蓋、青綠＝已涵蓋），取代「支撐已生成卻仍報孤島/懸垂錯誤」的舊矛盾 |
| **無支撐選項** | 材料與參數步驟可切換「有支撐 / 無支撐」，選無支撐時成本不會再套用預設的 15% 粗估支撐量 |
| **全螢幕檢視** | 工具列「⛶ 全螢幕」只會隱藏 portal 側欄填滿瀏覽器視窗，不會用瀏覽器原生全螢幕（保留書籤列、工作列） |
| **黑暗模式** | 由 portal 側邊欄的 🌙／☀ 統一控制（同源直接套用），quote-studio 頁面本身已無獨立切換鈕 |
| **工作類型倍率** | 成本分析面板可切換「代工 / 評估」，套用 admin/主管設定的計費倍率 |

### 4.4 列印時間估算（v2.3 重製）

列印時間改用「面積感知模型」：總時間 = 開銷（樹脂預熱等） + 每層基礎時間 × 層數 + 面積係數 × 固化體積 ÷ 層厚，並依所選材料套用實測校準的速度係數（12 種材料，含 Flexible 80A 等對層數特別敏感的材料）。比舊版「層數 × 固定係數」更能反映形狀差異（例如方塊跟高瘦件同層數但實際耗時不同）。**此模型每種材料僅用一個尺寸的真實列印校準，極大/極小件屬外插，僅供估算參考**，精確結果仍以實際切片/列印時間為準。

### 4.5 材料與價格設定（admin / 主管專屬）

側邊工具列「⚙ 設定」（僅 admin 或有 `manage_quote_pricing` 權限的主管可見）：

- **材料清單**：可新增/編輯/刪除材料（名稱、單價、密度），與 `quote.html` 舊版材料設定共用同一份 Firestore 清單
- **計費倍率**：分別設定「代工」「評估」兩種倍率，套用在成本小計（材料＋支撐＋後處理）之上

## 六、典型使用情境

### 情境 A：列印機完成一筆列印

1. Formlabs 機台列印完成
2. **30 分鐘內** Cloud Function 自動偵測並寫入 Firestore
3. 前端 onSnapshot 即時更新：
   - 機台狀態卡片更新（IDLE）
   - 消耗紀錄出現新一筆
   - 庫存頁「機台上 (L)」更新

### 情境 B：使用者手動換樹脂罐

1. 使用者拿備料一罐裝到機台上
2. Cloud Function 同步後「機台上 (L)」更新為新罐容量
3. ⚠️ **備料庫存「庫存 (L)」不會自動扣** — 需手動編輯：
   - 材料庫存頁 → ✏️ 編輯 → 該材料庫存減少 1 L → 儲存

### 情境 C：admin 設定安全庫存

1. 材料庫存頁 → 點「⚙️ 安全庫存設定」
2. 設定每個材料閾值（L）→ 儲存
3. 庫存低於閾值的材料顯示「需叫料」紅色標籤

### 情境 D：消耗紀錄出現 1970 年資料

Cloud Function 內建 `parse_valid_ts` 修正：Formlabs 偶爾回傳 epoch(1970) 的 `print_finished_at` 時，自動退回 `created_at` 使用。正常情況下使用者不需要處理。

### 情境 E：消耗紀錄顯示「未扣庫存」（v2.3）

代表這筆列印用的材料代碼版本號比系統目前已知的最新版本舊（例如家族最新是 FLTO2002，這筆是 FLTO2001）。系統判斷備料存的是新版本、舊版罐用量不該扣新版庫存，所以**只記錄不扣除**。正常情況下不需處理；若某材料家族其實仍有舊版本備料瓶在用，導致該家族庫存數字比實際多，請聯絡 admin 確認是否要為該家族加白名單排除此規則。

## 七、即時資料對應表

| 看到的數值 | 來源 | 更新頻率 |
|----------|------|---------|
| 預約清單 | Firestore `bookings` | 即時 (onSnapshot) |
| 預約狀態（執行中/已完成） | 依日期即時計算，不寫回 Firestore | 每次畫面渲染即時判斷，已完成/取消不會被自動覆蓋 |
